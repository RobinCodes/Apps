# Vendored WebView2 SDK header

`WebView2.h` from the `Microsoft.Web.WebView2` NuGet package, unmodified.

It lives in its own directory so the build can include it with `-isystem`.
The header is generated by MIDL and declares its interface GUIDs as
`EXTERN_C __declspec(selectany) const IID … = {…}`, which is valid for MSVC
but makes GCC warn on every one of the several hundred of them. `-isystem`
silences warnings from the header without silencing them for our own code,
which is why this is a directory rather than a loose file.

Nothing here is compiled directly; `win32/tab.c` is the only file that
includes it. The matching **runtime** is a separate thing and is not
vendored — it ships with Microsoft Edge.

Replace it by downloading a newer package and copying
`build/native/include/WebView2.h` over this one.
